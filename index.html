🔑 APIキー取得手順

Googleのルール上、取得にはクレカ登録が必要ですが、このアプリの利用範囲なら無料です。

  1. Google Cloud Consoleへ
  2. 「プロジェクト作成」
  3. 「YouTube Data API v3」を検索して有効化
  4. 認証情報 → APIキー作成
  5. ※複数アカウントで作成したキーを入力すると制限が緩和されます！
